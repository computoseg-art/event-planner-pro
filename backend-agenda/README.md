# Backend histórico

Este directorio corresponde al servidor anterior basado en Express.

## Estado

No es el backend de producción y no debe desplegarse.
La implementación vigente está en [`../functions/`](../functions/).

## Motivo para conservarlo

Permite comparar la lógica anterior durante mantenimiento y conserva el
catálogo usado por parte del frontend.

No configure credenciales nuevas aquí. Use Firebase Functions, Secret Manager y
las instrucciones de [`../guia.md`](../guia.md).
